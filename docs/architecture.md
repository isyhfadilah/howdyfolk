# Architecture

Next.js App Router, React, strict TypeScript, Tailwind/PostCSS, layered artwork composition and browser Canvas PNG export. Features live in src/features; app owns routes. Supabase cookie authentication, PostgreSQL/RLS migration, private Storage delivery and server-only Gumroad activation/reverification are implemented but require external setup. Vitest covers purchase policy; Playwright checks the running free builder. Vercel deployment and editable production SVG artwork remain unfinished. See setup.md for activation and validation requirements.
